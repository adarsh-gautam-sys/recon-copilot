Architectural Note — Foundations of Agentic AI

Pure LLM agents fail in financial control because unconstrained generation optimizes for plausibility rather than provability. Reconciliation Copilot separates symbolic verification (Stage 1 exact & tolerance joins over amount, reference, and settlement window) from bounded neural escalation (Stage 2 candidate ranking with a code-enforced confidence gate).

Verdict(x) = RuleMatch(x) [conf = 1.0] ∨ (LLMProposal(x) ∧ conf(x) ≥ τ) ∨ ExceptionQueue(x)
